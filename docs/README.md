## 📝 Documentation Standards

### Markdown Formatting

- Use headers for sections (#, ##, ###)
- Use tables for structured data
- Use code blocks for code examples
- Use lists for items
- Use checkboxes for status (✅, ⏳, ❌)

### Status Icons

- ✅ Complete
- 🚧 In Progress
- ⏳ Planned
- ❌ Not Started/Blocked
- 🔴 High Priority
- 🟡 Medium Priority
- 🟢 Low Priority

### Code Examples

Always include:

- TypeScript types
- Usage examples
- Props documentation
- Return values
